# 03. 초 단위 스토리보드 (1080×1920, 30fps, 30초)

장면 전환은 5프레임 안팎의 짧은 페이드로, 빠르지만 따라갈 수 있게 했습니다.
소리: 터치음은 짧고 낮게, 배경은 아주 작은 화음 패드(원본 합성음, 외부 음원 없음).

| 시간 | 장면 | 화면에서 일어나는 일 | 화면 문구 | 소리 |
|---|---|---|---|---|
| 0.0–0.4 | S1 | 어두운 차콜 배경. 긴 필름 스트립(원본 타임라인)이 올라옴 | | |
| 0.3–1.0 | S1 | 스트립 위에 붉은 구간 표시 3개가 차례로 켜짐 | 긴 영상, 매력적인 숏폼으로. | 터치음 3회(0.5, 1.3, 1.9초) |
| 1.2–2.2 | S1 | 구간 3개가 세로 숏폼 카드 3장으로 빠져나옴(색이 각각 다름) | | |
| 2.0–3.0 | S1 | 하단에 온고잉 로고 등장 | | |
| 3.0–3.8 | S2 | 휴대폰이 아래에서 올라옴. 접수 페이지 표시 | 파일도, 링크도 간편하게. | |
| 4.0–5.0 | S2 | "영상 파일 선택" 버튼이 눌림(깊이감) → 파일 칩과 진행바 | | 터치음 4.0, 4.15초 |
| 5.1–7.0 | S2 | "또는" 아래 유튜브 링크칸에 주소가 입력됨 | | |
| 7.0–8.0 | S3 | 선택 카드 2장(내가 구간 정해주기 / 온고잉이 알아서) 등장 | 직접 정하거나, 편하게 맡기거나. | |
| 7.9–9.0 | S3 | 첫 카드 탭 → 절제된 붉은 빛, 이어서 둘째 카드 | | 터치음 8.0, 8.85초 |
| 9.0–11.0 | S3 | 두 카드 아래에서 선이 내려와 한 점으로 합쳐지고 로고 마크, "두 방식 모두 제작으로 이어져요" | | |
| 11.0–12.5 | S4 | 두 레인이 나란히 열림: 왼쪽 직접 / 오른쪽 자동 | 원하는 스타일을 미리 보고 | 터치음 11.5초 |
| 12.5–14.5 | S4 | 왼쪽: 구간 3개 지정 → 제목 입력(가상 제목). 오른쪽: 내용 분석 진행바 → 분석 완료 | | 터치음 12.6, 13.6초 |
| 14.5–16.0 | S4 | 왼쪽: 템플릿 3종 미리보기에서 "여행" 선택. 오른쪽: 하이라이트 선별 → 스타일 적용에서 "정보" 선택 | | 터치음 14.7, 15.8초 |
| 16.0–18.0 | S4 | 두 경로가 아래로 모여 "제작 단계로" | | 합류음 17.3초 |
| 18.0–19.0 | S5 | 완성된 숏폼(휴대폰)과 운영자 검수 패널 등장. 제목·자막·"예시 댓글" 표시 | AI로 돕고, 사람이 확인합니다. | |
| 19.3–22.3 | S5 | 검수 항목 제목 → 자막 → 댓글 → 소리가 차례로 체크됨(소리는 막대가 움직임) | 제목·자막·댓글·소리를 직접 확인 | 확인음 4회(19.4, 20.3, 21.3, 22.2초) |
| 22.3–24.0 | S5 | "검수 후 전달해요" | | |
| 24.0–27.0 | S6 | 고객 완료 페이지: 검수 완료 표시, 완성본 미리보기, 다운로드 버튼 눌림 | 검수한 완성본을 링크로 | 터치음 26.0초 |
| 27.4–30.0 | S6 | 휴대폰이 물러나고 로고 확대 → 마무리 문구 + CTA | 영상은 보내고, 편집은 온고잉. / 전용 링크에서 시작하세요 | 마무리 음 27.6초 |

## 요청서 초안과 달라진 점
1. 핵심 메시지를 S3 내레이션으로 올렸습니다(초안에는 문구가 없었음).
2. S4(7초)는 두 경로를 앞뒤로 보여주지 않고 **좌우 레인으로 동시에** 진행해, 길이 안에서 둘 다 이해되게 했습니다.
3. S6을 둘로 나눠 완료 페이지(24–27초) 뒤에 로고와 CTA(27.4–30초)를 두었습니다.
4. S2 도입의 로고는 S1에서 한 번 보여서 접수 화면의 작은 로고로만 반복했습니다.

## 디자인 근거 (요청서 [5])
- 차콜 배경, 아이보리 휴대폰 화면과 글자, 포인트는 붉은색 하나. 금속 느낌 효과나 번쩍임은 쓰지 않았습니다.
- 버튼은 눌릴 때 그림자가 줄고 몸체가 내려가는 깊이감, 선택은 붉은 테두리와 약한 빛만 사용.
- 로고 마크는 필름 구멍과 재생 버튼으로 입체감(그림자·그라데이션)을 준 **임시 마크**이며 회전하지 않습니다.
- 사용한 영상·음원은 없습니다. 모든 화면은 코드로 그렸고 소리는 코드로 합성했습니다.
